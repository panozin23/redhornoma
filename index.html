Repositorio de RedHornoma

RedHornoma es el sistema para las computadoras de un centro de salud: la red interna, los programas del Ministerio dentro de Windows, y el respaldo que se hace solo.

Aquí se publican sus mejoras. Una vez añadido este origen, un centro las recibe con apt upgrade, sin reinstalar y sin pendrive.

Añadirlo a una computadora

Solo hace falta una vez. Las instaladas con el ISO ya lo traen puesto.

sudo mkdir -p /usr/share/keyrings
wget -qO- https://panozin23.github.io/redhornoma/redhornoma-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/redhornoma.gpg > /dev/null

echo "deb [signed-by=/usr/share/keyrings/redhornoma.gpg] https://panozin23.github.io/redhornoma trixie main" \
  | sudo tee /etc/apt/sources.list.d/redhornoma.list

sudo apt update
sudo apt install redhornoma-completo

Recibir las mejoras

sudo apt update && sudo apt upgrade

Qué instala. El informe del equipo, la virtualización de Windows, la red del centro, el respaldo automático, los periféricos y la pantalla única de control.

Software libre, construido sobre Debian, KDE, QEMU y decenas de proyectos más.
